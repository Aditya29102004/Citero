# Image Placement Instructions

Please place your uploaded images in the `public` folder with the following names:

## Required Images for Homepage:

### Hero Section:
1. **`dashboard-charts.png`** 
   - The dashboard screenshot showing Sentiment Distribution and Visibility Trend charts side-by-side
   - Used in the Hero section

### Product Preview Section:
2. **`dashboard-full.png`**
   - The full AI Perception Dashboard screenshot showing the complete dashboard interface
   - Used in the Product Preview section

### Features Section (Dashboard Cards):
3. **`understand-ai-card.png`**
   - Screenshot of the "Understand What AI is Saying About Your Brand" dashboard card
   - Shows brand visibility, top sources, competitor comparisons

4. **`track-visibility-card.png`**
   - Screenshot of the "Track AI Visibility" dashboard card
   - Shows visibility score (e.g., 85.2%) with trend indicators

5. **`find-sources-card.png`**
   - Screenshot of the "Find Sources Referenced by AI" dashboard card
   - Shows top sources list (Medium, Forbes, Wikipedia, etc.)

6. **`compare-competitors-card.png`**
   - Screenshot of the "Compare Competitors" dashboard card
   - Shows competitor rankings table with market share

7. **`boost-visibility-card.png`**
   - Screenshot of the "Boost Product Visibility" dashboard card
   - Shows actionable recommendations with priority badges

### FAQ Section:
8. **`faq-table.png`**
   - The FAQ/Question-Answer table interface screenshot
   - Shows the question-answer pairs in table format
   - Used in the FAQ section

## Image Requirements:

- **Format**: PNG, JPG, or JPEG
- **Location**: Place all images directly in the `public` folder
- **Naming**: Use exact filenames as listed above (case-sensitive)
- **Optimization**: Recommended to optimize images for web (compress, resize if needed)

## Example Structure:

```
public/
  ├── dashboard-charts.png
  ├── dashboard-full.png
  ├── understand-ai-card.png
  ├── track-visibility-card.png
  ├── find-sources-card.png
  ├── compare-competitors-card.png
  ├── boost-visibility-card.png
  ├── faq-table.png
  ├── favicon.ico
  └── robots.txt
```

## Notes:

- The homepage will automatically load these images
- If an image is missing, the code will hide the image element (no broken image icons)
- All images should be optimized for web to ensure fast loading times
- Recommended image dimensions:
  - Dashboard cards: ~800x600px or similar aspect ratio
  - Full dashboard: ~1200x800px or similar
  - Charts: ~600x400px or similar
